# Execution Plan: feat-mattpocock-adapter

## Goal
Ship the `mattpocock-skills` bundled adapter (plan 2 of the approved
skill-base-agnostic spec, minus the deferred `authoring-skillset-adapters`
skill) so this repo can pilot Matt Pocock's skills in place of superpowers,
with review-gated docs staying in the kb and process artifacts (tickets,
wayfinder maps) living on GitHub Issues with pointers in the plan doc.

## Approach
Mirror the superpowers adapter end to end: same adapter.yaml grammar, same
schema-test pattern (no network in CI; the generic engine/installer tests
already cover nested layouts via the synthetic fixture tree). The tracker
contract lives in a repo doc (`docs/agents/issue-tracker.md`), matching
upstream's config-driven design, so the patch series stays minimal.
Pilot swap (`rcorn skills install mattpocock-skills` in this repo, creating
the `ready-for-agent` label) happens post-merge as a local action — adapter
installs are gitignored; nothing to commit.
