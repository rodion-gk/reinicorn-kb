# Rich interactive TUI for reins init

## Description

Arrow-key selection, colored output, descriptions for each option during
`reins init`. Would require a new dependency (`questionary` or
`simple-term-menu`).

**Deferred from:** M2 (Init Rework + Onboarding) in the MVP roadmap.

Nice UX improvement but the flag-driven non-interactive mode covers the
functional need for MVP. Revisit once the core init flow is proven.
