# Delta specs + archive-merge lifecycle (from OpenSpec): express each change as AD

## Description

Delta specs + archive-merge lifecycle (from OpenSpec): express each change as ADDED/MODIFIED/REMOVED requirement deltas against a living current-behavior spec corpus; archiving semantically merges deltas at requirement level. Anti-drift by construction and yields a dated decision ledger — composes with the kb-aggregation bet.
